## What was built

- `keyboard/Predictions/PredictionBarProvider.swift`: a `PredictionProvider` that merges a `ShortcutExpander`'s expansion into slot one and a completions `PredictionProvider`'s output into the rest, capped at `limit` (default 3). It imports nothing. It depends only on `PredictionCandidate`, `PredictionProvider`, and `ShortcutExpander`, all declared elsewhere in the `keyboard` target, so it needs no UIKit, no Observation, no HangulEngine.
- `keyboard/Predictions/PredictionBar.swift`: a SwiftUI view rendering exactly three equal-width slots at `HeightMetrics.predictionBarHeight`, separated by two 1pt dividers colored `Color(.secondaryKeyboardButton)`. An empty slot renders `Color.clear` at the same size as a filled slot, so the `HStack`'s height never changes with the candidate count. A filled slot is a plain-style `Button` showing `candidate.display`, calling `onSelect(candidate)` on tap; the whole slot frame is tappable via `.contentShape(Rectangle())`, not just the glyph. The background is `Color(.keyboardBackground)`, the same asset `KeyboardView` uses, so both adapt to dark mode together with no new color asset. Text uses a fixed size derived from `KeySize`, the same way `KeyFace` does, so it does not scale with Dynamic Type while the keys next to it stay fixed. On wide layouts the slot content is capped to the same 500pt `KeyboardView` centers its grid at; the background stays full width.
- Hiding the bar when the setting is off is the view's own job: `PredictionBar` takes `isShown: Bool` and renders nothing, at zero height, when it is false. The composition root passes `model.isPredictionEnabled` straight through: `PredictionBar(candidates: driver.candidates, isShown: model.isPredictionEnabled, keySize: model.keySize, onSelect: driver.apply)`, and `HeightMetrics.inputViewHeight(for:predictionBarShown:)` still takes the same setting for the surrounding layout.

## Merge rules

Implemented in `PredictionBarProvider.candidates(textBeforeCursor:composing:)`, pinned by the 23 tests in `PredictionBarProviderTests.swift` (below): 12 in the original merge-rule suite, 11 in the `TruthTableTests` suite added for verifier finding 3.

| Rule | Behavior |
| --- | --- |
| Slot one | `shortcuts?.expansion(textBeforeCursor:composing:)` when `shortcuts` is non-nil and returns a candidate. A nil `shortcuts` or a nil expansion leaves slot one to the completions provider |
| Remaining slots | `completions.candidates(textBeforeCursor:composing:)` in its own returned order, one candidate per remaining slot |
| Duplicate skip | A completion whose `insertion` equals the `insertion` of any candidate already placed (the shortcut or an earlier completion) is skipped. The comparison is on `insertion`, not `display` or the whole struct |
| Cap | At most `limit` candidates total, `limit` defaults to 3. The loop over completions stops (`break`) once the cap is reached, so a completion past the cap is never inspected for a duplicate either |
| `limit` 0 or less | Empty list. The shortcut is never even requested when `limit <= 0` |
| Text passthrough | `textBeforeCursor` and `composing` are passed to both `shortcuts.expansion` and `completions.candidates` unchanged, once each |

## `PredictionBarProvider.swift` surface, verbatim

```swift
@MainActor
final class PredictionBarProvider: PredictionProvider {
  private let shortcuts: (any ShortcutExpander)?
  private let completions: any PredictionProvider
  private let limit: Int

  init(shortcuts: (any ShortcutExpander)?, completions: any PredictionProvider, limit: Int = 3) {
    self.shortcuts = shortcuts
    self.completions = completions
    self.limit = limit
  }

  func candidates(textBeforeCursor: String, composing: String) -> [PredictionCandidate] {
    guard limit > 0 else { return [] }

    var merged: [PredictionCandidate] = []
    if let shortcut = shortcuts?.expansion(textBeforeCursor: textBeforeCursor, composing: composing) {
      merged.append(shortcut)
    }

    // Slot one is reserved for the shortcut. The completion provider fills the rest in its
    // own order, and a completion that repeats an earlier slot's insertion is dropped rather
    // than shown twice.
    for candidate in completions.candidates(textBeforeCursor: textBeforeCursor, composing: composing) {
      guard merged.count < limit else { break }
      guard !merged.contains(where: { $0.insertion == candidate.insertion }) else { continue }
      merged.append(candidate)
    }

    return merged
  }
}
```

## `PredictionBar.swift` surface, verbatim

```swift
import SwiftUI

struct PredictionBar: View {
  private static let slotCount = 3

  let candidates: [PredictionCandidate]
  let isShown: Bool
  let keySize: KeySize
  let onSelect: (PredictionCandidate) -> Void

  var body: some View {
    if isShown {
      HStack(spacing: 0) {
        ForEach(0 ..< Self.slotCount, id: \.self) { index in
          if index > 0 {
            Rectangle()
              .fill(Color(.secondaryKeyboardButton))
              .frame(width: 1)
              .padding(.vertical, 12)
          }
          slot(at: index)
        }
      }
      .frame(maxWidth: 500)
      .frame(maxWidth: .infinity)
      .frame(height: HeightMetrics.predictionBarHeight)
      .background(Color(.keyboardBackground))
    }
  }

  @ViewBuilder
  private func slot(at index: Int) -> some View {
    if candidates.indices.contains(index) {
      let candidate = candidates[index]
      Button {
        onSelect(candidate)
      } label: {
        Text(candidate.display)
          .font(.system(size: keySize.fontSize))
          .lineLimit(1)
          .minimumScaleFactor(0.6)
          .foregroundStyle(Color.primary)
          .frame(maxWidth: .infinity, maxHeight: .infinity)
          .contentShape(Rectangle())
      }
      .buttonStyle(.plain)
    } else {
      Color.clear
        .frame(maxWidth: .infinity, maxHeight: .infinity)
    }
  }
}
```
