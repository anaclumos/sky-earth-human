## Derivation

- Every rendering expectation was replayed through `docs/oracle/automaton_oracle.py` before it was written into Swift. The replay covers 139 expectations and reports zero mismatches.
- `canExtend` expectations come from a bounded reachability closure over the same automaton. A candidate is reachable when some sequence of presses leaves the block count unchanged and renders the last block as the candidate.
- Reachable set sizes measured that way. From the state rendering U+AC00 there are 112 reachable syllables, from U+AC08 there are 11, from U+AC01 there are 4, from U+1100 U+119E there are 252, from U+AE30 there are 140, from U+3131 there are 1764, from U+3163 there are 0.

## Deviation from the task text

- The task asked for the BP on compound final case exactly as PLAN.md prints it, so that the state rendering U+AC4B plus BP renders U+AC4E. Those two code points do not reproduce.
  - U+AC4B is HANGUL SYLLABLE GYAS. Its final is U+3145, which is simple, not compound. The automaton answers U+AC4B U+3142 for it, and the v1.1 map has no entry for it at all.
  - The state that behaves as PLAN.md describes is U+AC0B, HANGUL SYLLABLE GALB, whose final is the compound U+313C. The v1.1 map entry for it is U+AC08 U+314D, which is the value PLAN.md quotes, and the automaton answers U+AC0E.
  - The suite pins U+AC0B plus BP to U+AC0E. PLAN.md line 48 appears to carry a transcription slip of 0x40 in both code points and is worth correcting at the source.

## Interpretations the engine must match

- Backspace at the last remaining keystroke returns a `Composition` whose `composing` is empty. The following backspace returns nil. The contract only says nil when nothing is composing.
- The cycle lock is measured from the previous press of the same key, not from the first press of the run. Three presses at 900 ms apart under a one second lock cycle three times.
- `Composition` needs a public memberwise initializer. The stub has one and `Typist` builds a seed value with it.
- A press that starts a new jamo after the lock expires renders as a new block beside the previous one, matching how the automaton renders any appended lone consonant.
