## Decisions

Decided by the orchestrator and implemented as stated.

- `press` returns `committed` empty and `composing` as the rendering of every block since the composition began. Blocks are never committed one by one.
- `commit()` returns the rendering as `committed`, an empty `composing`, and clears history. The composer is idle afterwards and `backspace()` returns nil.
- `backspace()` restores the previous snapshot. When that empties the composition it returns both strings empty and the composer is idle.
- Final consonant migration follows the oracle. A vowel after a simple final moves the whole final. A vowel after one of the eleven compound finals moves its second half only.
- The 399 BP cases on a compound final follow the automaton. U+AC4B plus BP gives U+AC4E.
- `canExtend(to:)` returns true when idle.
- The manifest declares no test target. SwiftPM refuses to load a manifest whose test target directory is missing, and `Tests/**` belongs to E2. With no test target `swift test` exits 1 with `error: no tests found`, so the gap cannot pass silently.

Cycle lock, as ruled.

- The interval is measured from the previous press and every press restarts it. It is not measured from the first press of a run.
- A press of the same consonant key later than `cycleLock` after the previous press starts a new consonant. A press at exactly `cycleLock` still cycles, so the comparison is `<=`.
- Cycling needs the immediately preceding press to be the same key. Any other key in between ends the run and the automaton decides.
- Vowel keys ignore the lock.

Decided in this node.

- One snapshot per keystroke holds the blocks, the key and the instant. Backspace therefore restores the lock instant of the press it returns to. `backspace()` takes no instant, so this is the only reading that stays a pure rewind.
- With the lock open, key-based cycling equals the oracle's state-based cycling. A trailing consonant jamo is always the product of the most recent consonant key, and the seven cycles are disjoint.
- Jamo tables hold `Unicode.Scalar`, not `Character`. Every jamo is one scalar, and `Character` equality normalizes on each comparison. The change cut `canExtend` cost by about 3.6 times and makes emitted code points exact by construction.
- Memory. History keeps a full block list per keystroke and grows until `commit()`. The extension commits on space, so a composition is one word.

## canExtend

Deviation from the decided definition. One condition is added.

| Reading | Rule |
| --- | --- |
| Decided | Some run of presses, lock open, no commit, leaves the block count unchanged and renders the last block as the character |
| Implemented | The same, and every block before the last ends unchanged |

Reason.

- A lone consonant behind a syllable can fold into that syllable as its final, after which a new block can grow into anything. The block count is back where it started, the last block is unrelated to what was being typed, and the block before it has changed.
- This state is common. It is how U+3138, U+3143 and U+3149 are typed after an open syllable.
- Measured on the oracle from U+AC00 plus a lone U+3138. The decided reading reaches 11,172 of 11,172 syllables and visits about 338,000 states per call. The implemented reading reaches 1,764, the syllables whose initial is U+3137, U+314C or U+3138.
- States without a foldable trailing consonant give identical results under both readings.
- Reverting means dropping the `next.dropLast() == anchor` condition in `Automaton.reach(from:)`. The inline lap does not depend on it. That form has not been run against the harness. The decided reading as first implemented is commit `e089d86`, which agreed with its reference on 2,978 single-block states.

The bound, and why it suffices.

- Presses change the last two blocks only, so the search runs on that tail. Checked on all 503,530 oracle pairs, 0 failures. `pressVowel` and `pressConsonant` read no block before those two.
- A block never loses its vowel or changes its initial once it has a vowel. Checked on the same pairs, 0 failures.
- The only block ever removed is a trailing lone consonant folding into the syllable before it. The block count moves by at most one per press. Checked on the same pairs, 0 failures.
- A state past the starting count can therefore only come back by cycling that consonant on its own key. A cycle has at most three jamo, so it folds within one lap or never. The lap runs inline and no state past the starting count is stored.
- A state at the starting count whose earlier block changed is dropped. That block is frozen while a later block exists, and a fold only grows its final further.
- The search is finite. A last block has at most 3 initials from one cycle, 24 vowel options counting none, and 28 finals, so at most 2,016 last blocks. The largest measured is 1,773, from a lone consonant.
- The engine cannot over-claim. Every rendering it collects sits on a real press path that satisfies the rule. The risk is over-pruning, which the checks below target.

## Rendering

- Syllables are `0xAC00 + (initial * 21 + medial) * 28 + final`. This equals NFC of the conjoining jamo sequence for all 11,172 syllables.
- The initial, medial and final table orders match the Unicode names at U+1100, U+1161 and U+11A7 plus index, for 19, 21 and 28 entries.
- A pending araea after an initial renders as U+1100 plus initial index, then U+119E or U+11A2. Without an initial it renders as U+119E or U+11A2 alone. A lone jamo renders as its compatibility jamo.
- All 11,172 precomposed syllables occur in the oracle universe and render back exactly.

## Public surface

From the emitted module interface.

```swift
public enum Key: CaseIterable, Sendable {
  case i, arae, eu
  case gk, nr, dt, bp, sh, jc, om
}

public struct Composition: Equatable, Sendable {
  public var committed: String
  public var composing: String
}

public struct HangulComposer: Sendable {
  public init(cycleLock: Duration)
  public var isComposing: Bool { get }
  public var composing: String { get }
  public mutating func press(_ key: Key, at instant: ContinuousClock.Instant) -> Composition
  public mutating func backspace() -> Composition?
  public mutating func commit() -> Composition
  public func canExtend(to syllable: Character) -> Bool
}
```

- Beyond this the interface holds only compiler-synthesized members of the declared conformances. `Key.allCases`, `Key` equality and hashing, `Composition` equality.
- `Block`, `VowelState` and `Automaton` are internal.
