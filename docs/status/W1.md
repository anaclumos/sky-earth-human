## Route for the change

Hand-edited `sky-earth-human.xcodeproj/project.pbxproj` with the Edit tool only. No scripted rewrite, no xcodegen or other generator run against the real project.

Before writing the diff, a throwaway spike project was built under a scratch directory with `xcodegen` (a local `SpikePkg` Swift package linked into a plain iOS app target) to confirm the exact pbxproj shape Xcode/xcodebuild expects for a local package dependency, then that spike was built with `xcodebuild` against the pinned Xcode 27 beta toolchain to confirm the shape actually links and runs, not just parses. The real edit mirrors the spike's shape:

- `XCLocalSwiftPackageReference` with a `relativePath` key pointing at the package folder, no other keys.
- `XCSwiftPackageProductDependency` with only a `productName` key (no `package` back-reference is required or written for a local package; a `package` key is used for remote packages when a product name is ambiguous across dependencies, which does not apply here).
- `PBXBuildFile` for the product dependency uses a `productRef` key, not `fileRef`.
- The build file entry goes in the target's Frameworks build phase `files` list, alongside `packageProductDependencies` on the target and `packageReferences` on the project object.
