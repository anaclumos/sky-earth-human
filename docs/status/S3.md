## Notable finding not asked for directly

The pad simulator's keyboard extension was simply not installed there partway through the run (stale derived-data state after an earlier interrupted session), which looked like a UI automation failure until `xcrun simctl spawn <udid> pluginkit -m -p com.apple.keyboard-service` showed the extension missing. Worth a general note for any future custom-keyboard testing on this iOS beta: check `pluginkit` before assuming a Settings automation bug.
